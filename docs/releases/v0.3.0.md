# cgx v0.3.0 — first public release

The release that makes cgx public: a fast, offline call-graph engine with a CLI
and an MCP server, for code navigation by developers, security analysts, and AI
agents — across Rust, TypeScript, Go, Java, and Python.

## Query power

- **Selector engine** — a language-blind node-selector engine wired into
  `cgx search` and CQL, so selections compose across the graph.
- **Callers locality tier** and **pack cards** sharpen and summarize results.

## Committable, shareable index

- **git-store** — a content-addressed object store for the graph, so an index
  is reproducible byte-for-byte and can live in git.
- **ref-overlay transport** — `cgx push` / `cgx pull` move an index over a
  non-branch `refs/cgx/*` ref, mirroring the committable set without touching
  your branches.

## Release engineering

- A reproducible release pipeline that mints a dated BUSL-1.1 `LICENSE` at tag
  time and ships a byte-reproducible binary with an attestable checksum.
- An audience-oriented README and reproducible fixture-based examples.
