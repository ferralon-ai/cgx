# cgx v0.1.0 — the five-language call-graph engine

The first cut of cgx: a deterministic engine that maps how a codebase calls
itself and answers structural questions about it from a persisted graph — no
daemon, no warm-up.

## Languages

Call-graph extraction across five languages, each via a tree-sitter adapter:
**Rust, TypeScript/JavaScript, Go, Java, and Python.** Files in any other
language are reported as unsupported rather than silently dropped.

## What you can ask

- **Navigation** — callers and callees of a function, as a flat list or a
  rendered forest/tree view.
- **CQL** — a Cypher-subset query language over the code graph for structural
  questions the fixed verbs don't cover.
- **Search** — locate symbols across the whole indexed workspace.
- **Diff / PR gate** — compute what a change reaches, as a CI-friendly gate.

## Foundations

- A single core graph data model (`cgx-core`) every other crate builds on.
- A sparse-first object store: the index is a build artifact, indexed on
  demand.
- Per-edge confidence is three-valued from the start — every answer is labelled
  with how much it is worth.
