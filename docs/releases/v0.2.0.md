# cgx v0.2.0 — answers you can trust in CI

v0.2.0 hardens the engine into something you can assert on: every answer states
what it is worth, names the tree it describes, and stays byte-stable across
runs.

## Trustworthy answers

- **Answer contract** — each result carries an approximation contract (exact,
  under-, or over-approximate) and the reason for it.
- **Confidence honesty** — the three-valued `certain` / `probable` / `possible`
  labelling was audited end to end so a label never overstates what was
  resolved.
- **Freshness envelope** — answers report which indexed tree they describe and
  whether the working tree has moved since.

## New questions

- **Change-coupling** — which files tend to change together, read from committed
  git history.
- **Impacted-tests** — which tests a change can reach, for test selection.
- **max-candidates** filtering and language-partitioned callers for sharper,
  faster results.

## Parity and health

MCP-tool parity with the CLI, TypeScript adapter parity, and a broad pass over
the doctor/stats wiring, output formats, and CI. Query answers are byte-identical
across independent indexes of the same source — safe to diff and to assert on.
